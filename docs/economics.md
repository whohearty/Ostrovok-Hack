# Экономика и бизнес-гипотезы · шаблон
Результаты не рассчитаны. Ответственный Миша, независимая проверка Максим. Конкурсное задание связывает пользу с удобством выбора и коммерческими результатами; доказательство роста без настоящего пилота отсутствует.

| Параметр | Формула/содержание | Статус сейчас |
|---|---|---|
| LLM cost/session | Σ(input_tokens×input_rate + output_tokens×output_rate)/единица тарифа | Нет замеров, провайдер не выбран |
| Tool cost/session | Σплатных вызовов + доля инфраструктуры | Неизвестно |
| Cost/success | Все затраты тестовых сессий / число успешных полных сценариев | Неизвестно;0 успехов означает отсутствие конечной оценки |
| GMV | Стоимость подтверждённых поездок | В прототипе синтетика, реального GMV нет |
| Revenue | GMV×комиссия или фактическая выручка | Комиссия — допущение, не факт о компании |
| Incremental contribution | Доп.выручка минус переменные затраты, поддержка и неуспешные сессии | Только будущая гипотеза |
| Build cost | Человеческие часы/ставки и отдельно затраты агентов | Не смешивать с runtime себестоимостью |

Сценарии низкий/базовый/высокий варьируют длину контекста, число уточнений, вызовов и долю успехов. Тарифы фиксируются ссылкой и датой после выбора провайдера. Нельзя записывать придуманные рубли или конверсию как измерение.

Для будущего пилота:доля пользователей, дошедших до валидного плана; до подтверждения покупки; время выбора; отказы; отмены; средний чек и повторный визит. Нужны источник базы, знаменатели, контроль, период, стоимость и критерий остановки. Рост среднего чека сам по себе не доказывает пользу, если он сопровождается ростом отказов или затрат.
